# Productr - Orufy Full Stack Assignment

Final full-stack project based on the shared Figma frames.

## Run Backend
```bash
cd server
npm install
copy .env.example .env
npm run dev
```

## Run Frontend
Open another terminal:
```bash
cd client
npm install
copy .env.example .env
npm run dev
```

Open `http://localhost:5173`
